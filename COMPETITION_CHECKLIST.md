- [ ] Open Google Gemini and run the planning prompt.
- [ ] Review and personalize the T-minus milestone plan.
- [ ] Ask Gemini to create/refine the lock-screen design using the mountain-summit reference.
- [ ] Review clock-safe spacing and mobile readability.
- [ ] Optionally set reminders in Gemini/Google Calendar as described in the mission.
- [ ] Test the web companion on a phone.
- [ ] Build and test the Android live wallpaper on a supported Android device, or build the iOS app + widget in Xcode.
- [ ] Upload the wallpaper PNG as the Handshake cover image.
- [ ] Paste project title and description from `submission/HANDSHAKE_SUBMISSION.txt`.
- [ ] Paste the real hosted web URL (not a local file URL).
- [ ] Submit one genuine entry before the deadline.

Do not submit an untested native build as if it were installed or published. Native project source is included; device builds require Android Studio/Xcode and platform signing.
